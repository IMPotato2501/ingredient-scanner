成分查查

英文成分表 → 中文名 + 添加剂分级

推荐用法（安卓）：相机打开 Google Lens → 对准成分表 → 选中文字 → 复制 → 回到这里粘贴。比网页拍照识别更准。

用手指在照片上拖一个框，框住成分表那一段。不框就识别整张。

识别引擎：

待查清单同步 ·

未识别的成分会自动记到你 GitHub 仓库里的 pending.json。需要一个只能改这个仓库的令牌（只用设置一次，存在这台手机里）。

正常：普通食材，或一般认为安全的添加剂

留意：适量即可，或安全性有讨论、特定人群需注意

尽量少吃：有较明确的健康担忧，或在其他国家被禁/限用

未识别：自动记入待查清单，之后统一查证归类

点任意一项可看简短说明。

成分表按含量从多到少排列，越靠前占比越大。分级仅供个人参考，不是医学建议。
